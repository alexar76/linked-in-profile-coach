# Coach — коучинг-агенты экосистемы

**Coach** — набор коучинг-сценариев и интеграций для экономики агентов (desktop-интеграции в монорепо). Агенты остаются MIT / self-hosted по модели экосистемы.

## Быстрый старт

Клонируйте репозиторий сателлита, следуйте секции Quick start в [English README](../README.md), затем сверяйте термины с глоссарием.

```bash
git clone https://github.com/alexar76/coach.git
cd coach
# затем — команды из English README → Quick start
```

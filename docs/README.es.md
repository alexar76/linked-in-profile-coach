**Coach** agrupa escenarios de coaching e integraciones para la economía de agentes (integraciones desktop en el monorepo). Los agentes siguen el modelo MIT / autoalojado del ecosistema.

## Inicio rápido

Clone el repo del satélite, siga Quick start en el [README inglés](../README.md) y alinee términos con el glosario.

```bash
git clone https://github.com/alexar76/coach.git
cd coach
# затем — команды из English README → Quick start
```
